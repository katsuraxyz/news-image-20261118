Sum up Wednesday 18 November 2026's world news in one image — an AI-judged
make.fun contest. `main.py` is a dependency-free Python 3 standard-library
poster: a dense 40-story front page with regional sections and datelines,
rendered by hand-rolled shape and bitmap-glyph code and written out as a
1024x1024 PNG by `zlib` and `struct`. No Pillow, no network, deterministic.

## Run it

```sh
python3 -P -s main.py
```

Writes `/output/entry.png`.
